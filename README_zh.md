## 两个版本的区别

严格版在模型计算前执行记录级筛选：任何实际参与节点或原始同次reach的总体质量不通过，或任一适用的 WSE、width、slope Hampel 标记成立，该条站点过境记录均排除。总体质量仅接受 node_q/reach_q 的0、1；这些是卫星质量码。筛选还包含既有站点Hampel和完整卫星序列Hampel。40条原始同次reach质量证据不完整的记录亦不输入模型，并单列“QC未核验”。

严格排除的 30,779 条记录存放在 data/strict/excluded_observations.csv，仅包含卫星输入、QC证据与排除原因，没有 Q 估算或模型中间量。严格版模型输入只包含通过筛选的记录。冻结宽度曲线和参数维持原值，因此本次筛选没有重新清理历史率定样本、改变历史参数或重新评估论文精度。

保留标注版保留此次全部 78,643 条现有存档过境记录，并沿用原参数、面积/宽度关系和坡度逻辑。这里的“全部”指本研究当前存档，之前上游处理已排除的原始节点记录没有重新恢复。两版共同记录的估算Q完全一致。

根据本次确认，两版通过QC后均保留原坡度逻辑：同次匹配坡度缺失或非正时，存档可能使用另一时刻的最近有效正坡度；原规则不限制最大时间差。来源可以早于或晚于当前过境，均显示“坡度替补”、来源时间和时间差。存档坡度仍缺失或非正时，模型使用该站保存的正坡度参考值，标记“参考坡度”。

## 简短标签与备注

表格显示“质量异常”“WSE异常”“宽度异常”“坡度异常”“水力外推”“坡度替补”“面积下限”“QC未核验”“无模型”等短标签。定义在网页备注区和 metadata/flag_definitions.csv；点击点或表格行可查具体字段。水力外推、宽度偏离冻结曲线、坡度偏离参考值等提示本身不作为严格排除条件；严格排除依据是总体质量与Hampel及证据完整性。

原始节点/河段Hampel复现已有QC：每个pass分别处理完整时间序列，前后3行、至少3个值，滚动中位数及偏差的二次滚动MAD，3倍稳健尺度。站点原有Hampel沿用存档标记。完整卫星序列采用前后5行的局地精确MAD，3倍尺度；WSE/width/log10(slope)尺度下限分别为0.02 m、1 m、0.05。这些筛查均不读取实测Q；标签用于复核，不能当作已知流量误差。

## 公共数据范围与适用条件

所有CSV、JSON及网页脚本均移除了实测流量、地面匹配日期/类别/状态、逐观测实测误差、训练NSE/R²和按实测误差生成的标签或筛选。Q_estimated是估算值。模型参数原先受到地面观测率定约束；其公开并不等于公开逐观测实测对照。WSE已使用研究的水位基准，不能作为未校正的官方绝对高程解释。

本包提供回顾性的存档重构。跨日期坡度和居中Hampel可能使用后续信息，这些结果不构成实时预测或独立时间前向验证。未配对推算记录无法验证真实Q误差。两个版本用于对比QC处理策略，不表示严格版精度已提高。

## 文件与复现

- data/strict、data/retained：总表与逐站完整CSV；严格排除清单单独保存。
- models：542站必要的冻结参数与宽度锚点，采用字段白名单。
- metadata：站点目录、字段字典、标签定义、汇总和地图来源。
- viewer：可修改的中英文HTML/CSS/JavaScript及离线站点数据。
- code/frozen_model.py：只接受卫星输入和冻结参数的推算程序。
- code/reconstruct_source_qc.py：原始同次QC证据恢复代码；需自行取得源卫星记录和参与节点映射，受限地面数据无需提供。
- checks：计算、字段脱敏、完整性和网页验证记录；SHA256SUMS.txt用于核验文件。

计算环境为Python3.13、NumPy2.3.1、pandas2.3.1；页面只需现代浏览器。可分别运行：

```powershell
python code/frozen_model.py --input data/strict/all_observations.csv --models models --output strict_reproduced.csv
python code/frozen_model.py --input data/retained/all_observations.csv --models models --output retained_reproduced.csv
```

输出文件应使用新名称。脚本只对所给版本的记录计算，不会合并排除清单。完整记录的行ID与QC规则让两版筛选可直接核对。


使用完整公开存档同时重建两个版本：

```powershell
python code/rebuild_variants.py --output rebuilt_variants
```
